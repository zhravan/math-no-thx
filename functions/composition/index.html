Function composition

Put one function inside another. Watch the output flow through both.

The idea

f(g(x))

The inside function runs first. Its output becomes the input of the outside function.

Composition

f(g(x)) = 6x - 1

g(x) = 3x - 1, then f(g(x)) = 2(3x - 1) + 1.
