Inverse functions

An inverse undoes a function. See the two graphs reflect across y = x.

The function

f(x) = x

For a linear function f(x) = ax + b, the inverse is f⁻¹(x) = (x - b) / a, when a ≠ 0.

The inverse

f⁻¹(x) = (x - 1) / 2

f(f⁻¹(x)) = x and f⁻¹(f(x)) = x

What to notice

The two graphs are reflections across y = x.

Input and output swap places.
